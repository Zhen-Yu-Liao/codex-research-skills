# Common Failure Modes

## AI Prose 過重

- 句子過度圓滑、抽象，但沒有新增資訊。
- 段落看起來正式，實際上沒有交代估計對象、條件或限制。

## Cross-Chapter Drift

- introduction 寫成 methodology。
- methodology 段落偷塞 literature review。
- conclusion 新增正文從未建立的新 claim。

## Citation 問題

- 引用 key 不存在。
- citation 存在，但不支撐正文的強主張。
- 為了句子順而假設某篇文獻涵蓋所有細節。

## Placeholder 破壞

- 把 intentional placeholder 刪掉，造成作者失去待補位置。
- 把 TODO 當成正式結論直接寫進正文。

## Theorem-Level Overclaim

- 用 heuristic 語句包裝成正式保證。
- 把 simulation 結果升格成一般性理論結論。
