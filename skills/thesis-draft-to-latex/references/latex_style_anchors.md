# LaTeX Style Anchors

## Section 層級

- 沿用現有章節的 `section` / `subsection` / `subsubsection` 深度。
- 不因為想讓架構對稱就新增不存在的層級。

## 數學與符號

- 先看現有章節如何定義符號，再決定是否新增。
- 短公式用 inline math，核心公式才升到 display math。
- 若專案已有 theorem、lemma、assumption 等環境，沿用現有寫法。

## Citation 使用

- 只使用已存在或已核實的 key。
- 引文節奏跟隨現有章節，不要突然改成密集 citation 堆疊。
- 若 claim 的語氣變強，citation 與正文證據也要同步補強。

## Placeholder 保留規則

- intentional placeholder 不要自動刪掉。
- 若 placeholder 代表缺資料或待確認假設，應在回覆中標記，而不是假裝已完成。

## Bridge Text 原則

- 需要 reader aid 時，優先補短的過渡句。
- 過渡句的功能是說明「為何現在進入下一段」，不是重複前文。
