# Argument Ladder Template

對每個 section 至少填滿以下欄位。若某欄目前未知，要明示缺口，而不是跳過。

## Template

```text
section_title:
section_goal:
must_keep:
claim_order:
required_evidence:
notation_or_definitions:
spillover_risk:
open_gaps:
recommended_next_step:
```

## 欄位說明

- `section_title`: 暫定標題或現有標題。
- `section_goal`: 本節要回答什麼問題，讀者讀完後應得到什麼定位。
- `must_keep`: 不能刪的定義、文獻、實驗設定、圖表或邏輯節點。
- `claim_order`: 核心論點的順序，避免先講結論再補前提。
- `required_evidence`: 每個論點需要哪些 citation、公式、圖表、表格或實驗。
- `notation_or_definitions`: 這一節必須先定義哪些符號、估計對象或任務設定。
- `spillover_risk`: 哪些內容其實應留給其他章節，例如 literature review、methodology、simulation 或 conclusion。
- `open_gaps`: 目前缺哪些證據、轉場、橋接句或外部來源。
- `recommended_next_step`: 下一步該繼續規劃、交給成稿 skill，或先回去補資料。

## 使用原則

- section 的粒度以可執行為準，不必為了形式把每節都切成同樣大小。
- 若使用者明確要求保留原有 wording，優先做段落功能與順序調整，不主動改寫句子。
