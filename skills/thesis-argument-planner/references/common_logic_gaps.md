# Common Logic Gaps

## Claim / Evidence 錯位

- 研究缺口寫得很大，但後面的 contribution 只補到局部工程細節。
- 圖表只展示數值差異，正文卻升格成理論或普遍性保證。

## Notation Drift

- 前後段落使用同一符號，但意義已經改變。
- methodology 與 empirical chapter 對同一估計目標的描述不一致。

## Contribution Overclaim

- 把 matrix-level bound 說成 estimator-level guarantee。
- 把計算上可行說成統計上優越。
- 把 heuristic observation 說成 theorem-level 結論。

## Empirical Setup 缺口

- baseline 不完整。
- metric、tuning、stopping criterion 或硬體環境未交代。
- 只呈現成功案例，沒有說明方法邊界。

## Structure Problems

- background 與 introduction 重複。
- conclusion 引入新資訊。
- 章節之間缺 bridge text，導致 reader 無法理解為何轉場。
