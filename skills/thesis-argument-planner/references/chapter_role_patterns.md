# Chapter Role Patterns

## Introduction

- 交代問題、研究缺口、方法定位、主要貢獻與章節安排。
- 不要把大量方法細節或完整 empirical 結果提前塞進來。

## Background / Literature Review

- 比較相關方法的研究目標、假設、估計對象、計算規模與保證類型。
- 不要把它寫成 paper 摘要堆疊。

## Methodology

- 定義符號、目標、模型、演算法、理論命題與條件。
- 不要把 implementation note 誤寫成統計保證。

## Simulation

- 交代 data-generating process、baseline、metric、tuning、資源環境與結果解讀。
- 不要只報最好看的 case，也要交代邊界與失敗情境。

## Real Data

- 交代資料來源、欄位語義、前處理、任務設定與主要實證觀察。
- 若前處理或 cutoff 有理由，應可追到 citation 或資料文件，不靠推測。

## Conclusion

- 收斂全文貢獻、限制與下一步。
- 不新增正文沒有證成的新 claim。
