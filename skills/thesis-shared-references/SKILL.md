# Thesis Shared References

This is a support skill for thesis workflows. It exists so GitHub-based skill installers can install the shared convention files together with the thesis workflow skills.

## How To Use

- For thesis argument planning, use `thesis-argument-planner`.
- For citation and claim support review, use `thesis-citation-logic-auditor`.
- For turning drafts into formal LaTeX thesis prose, use `thesis-draft-to-latex`.
- For LaTeX build, entry wiring, citation/reference, and artifact checks, use `thesis-build-guard`.

Use this skill directly only when the task is to inspect, revise, or explain the shared thesis conventions themselves.

## References

- `thesis_base_conventions.md`: general thesis writing, editing, citation, and reader-guidance conventions.
- `statistics_thesis_conventions.md`: optional domain conventions for statistics, methodology, or math-heavy empirical thesis tasks.
